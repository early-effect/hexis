# AGENTS.md

Guidance for agents working in **hexis** (`early-effect/hexis`). Scala 3 / ZIO 2 SDK for TypeSafe System One. Published to Maven Central as `rocks.earlyeffect::hexis` (JVM, JS, Native).

## Layout

| Path | Role |
| --- | --- |
| [`core/`](core/) | Published library. `sbt-projectmatrix`: JVM, Scala.js, Native. |
| [`example/`](example/) | Unpublished cookbooks (hierarchy, SDE cascade, demos). JVM. |
| [`docs/`](docs/) | Specular DocSpecs. Not published. |
| [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | Generated by zipx. Do not hand-edit. |

Root aggregates `core`, `example`, and `docs` and skips its own `publish` / `test`.

## Commands

sbt 2: `test` is `testQuick` and can skip. Use **`testFull`** for proof. Prefer Metals `compile-file` then Metals `test` while iterating. Join Metals' BSP with `sbt --no-server`.

```bash
sbt compile
sbt testJVM
sbt testJS
sbt testNative
sbt testLive
sbt docs/specularSite
sbt --no-server ~docs/specularPreview
sbt zipxWorkflowGenerate
```

Live TypeSafe calls are tagged `hexis.live` (`sbt testLive`). The org-gated `live` zipx job is added after `JEV_API_KEY` is seeded.

## Conventions

- Scala 3 only: `enum`, `given`, `derives`, optional braces. Scalafmt: max 120, `align.preset = more`.
- `-Wunused:all`.
- Errors are `JevError`. Do not extend Exception.
- Heddle types do not leak from `import hexis.*`. `Transport.heddle` is the explicit escape.
- No AI attribution in commits or PR text.
